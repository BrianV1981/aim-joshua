# A.I.M. Foundry
Stage plain-text documentation or source code directories here (supported extensions: `.md`, `.markdown`, `.txt`, `.py`, `.rs`, `.js`, `.ts`, `.rst`) before compiling them into portable `.parquet` ROM cartridges via `./aim bake <dir> <output.parquet>` (requires local Ollama embeddings) or indexing directly into `memory_lance` via `./aim index --dir <dir>`.
