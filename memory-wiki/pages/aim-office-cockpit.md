# AIM-Office — 2.5D Isometric Multi-Vessel Fleet Cockpit (`~/aim-office`)

## 1. Overview & Purpose
`aim-office` (`https://github.com/BrianV1981/aim-office`, GitHub Project `#14`, MIT License) is the sovereign, original-IP 2.5D isometric fleet command center for the J.O.S.H.U.A. / A.I.M. ecosystem. Running on `http://localhost:5175`, it visualizes up to 32 live `tmux` agent vessels across 8 elastic 4-Way Parallel Quad Bench pods, streams 30%-Rule Context Window telemetry (`🟢 <20%`, `🟡 20–29%`, `🔥 >=30% AMNESIA`), animates physical `aim-communicate` Courier Walks across an A*/BFS waypoint graph, and provides a floating, draggable 2-column Agent Cockpit (`AgentInspectorDrawer.tsx`) with live `tmux` scrollback, SpeechSynthesis TTS, Web Speech API Mic STT dictation, 1-tap macro pills, and a 1-click `aim-communicate` broker.

## 2. Core Architectural Pillars (`#1`–`#10`)
1. **Clean-Sheet 2.5D Isometric Engine (`1376x768`, `16:9`):**
   - Bottom-center sprite anchoring (`transform: translate(-50%, -100%)`) with dynamic depth sorting (`zIndex = Math.round(y * 10)`).
   - **Bottom-Anchor Vertical Compensation (`-5.3%`):** Because desks (`height: 9.0%`) and characters (`height: 9.2%`) anchor at their bottom edge, a 4-desk quad pod centered at `(cx, cy)` renders visually from `cy - 13.65%` (top of rear agent's head) to `cy + 3.05%` (bottom of front agent's feet). All room pod coordinate tables (`QUAD_POD_CENTERS`, `WAR_ROOM_POD_CENTERS`, `CUTAWAY_AGENCY_POD_CENTERS` in `src/office/rooms.ts`) compensate for this upward shift.
   - **Parallel 2×2 Isometric Quad Benches (`SLASH_BENCH_SLOTS` & `BACKSLASH_BENCH_SLOTS`):** Rear-row agents (`NW`, `NE`) use `zIndexOverride = deskZIndex - 5` (standing behind rear desks with lower legs occluded), while front-row agents (`SW`, `SE`) use `zIndexOverride = deskZIndex + 5` (standing in front of front desks facing monitors).
   - **Elastic Pod Scaling (`computeElasticPodCount` & `filterRoomForAgentCount`):** Scales dynamically from 4 pods (`16` desks for `<= 16` agents) up to 8 pods (`32` desks for `17..32` agents), with mouse-wheel zoom (`0.75x..1.8x`) and click-and-drag camera pan.

AI Neural Core Reactor**, Left Bulkhead **WOPR Mission Control Telemetry Wall**, Right Bulkhead **A.I.M. Memory Vault + Swarm Portal**, and **Central Octagonal Holographic Globe Table**. Keeps `x = 50%` unobstructed, places 8 pods symmetrically in Left (`slash`) and Right (`backslash`) conduit bays with dark gunmetal/cyan console desk grading, and sets `wallBoardRect: null` (no floating wall whiteboard).
   - **Direction A — Multi-Zone Cutaway Agency (`cutaway-agency`):** Unobstructed 3-alcove cutaway floorplan (`public/rooms/agency-floorplan-day.png` & `agency-floorplan-night.png`) with Raised West Server Platform, Recessed Center `J.O.S.H.U.A. HQ` Doors + LED News Ticker, Right Strategy Wing with a flat front-facing Whiteboard (`skewDeg: 0`, `variant: 'glass-board'`), and 4 woven area rugs.
   - **Classic A.I.M. Executive Studio (`classic-command`):** Sunlit hardwood floor (`public/rooms/office-day.png` & `office-night.png`) with isometric right-wall dry-erase Kanban whiteboard (`skewDeg: 25.6`).
