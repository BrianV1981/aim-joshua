# Handoff & Retrieval Protocols

## The Handoff Pipeline & Memory State Exemption
Agent Memory (`memory-wiki/**` and `HANDOFF.md`) is treated as living OS memory state rather than application code, explicitly exempt from GitHub Issues and `workspace/issue-*` worktrees:
1. **Mid-Session Checkpoint (`aim-memory-wiki`):** Can be run autonomously mid-session as a ~15-second "Save Game" that updates `memory-wiki/index.md`, `memory-wiki/log.md`, and `memory-wiki/pages/*.md`, runs `./aim index` if LanceDB is active, and pushes directly to `origin/main` (`git add memory-wiki/`, commit, `git pull --rebase --autostash origin main`, `git push origin main`) with zero prompts and without ending the session.
2. **One-Command Session Closeout (`aim-handoff`):** When ending a session, `aim-handoff` executes an **Idempotent Auto-Wiki Delta Check** first (inspecting `memory-wiki/log.md` and automatically updating `memory-wiki/` if unlogged session work occurred), surgically updates `HANDOFF.md` (`0–9` template), and pushes both `memory-wiki/` and `HANDOFF.md` directly to `origin/main` in a single atomic commit (`git add memory-wiki/ HANDOFF.md`, commit, `git pull --rebase --autostash origin main`, `git push origin main`) with zero confirmation prompts.
3. **Blackbox Vault & `/aim-sessions` Notebook ([Blackbox Vault](blackbox-vault.md)):** Before exiting the current session, the agent MUST seal the session into the immutable, Operator-locked blackbox vault (`aim agy-blackbox --session-id <uuid>`, `aim grok-blackbox`, `aim codex-blackbox`, `aim opencode-blackbox`), honoring `--vessel-root` for cross-directory isolation (`#132`), resolving Antigravity 2.0 (`~/.gemini/antigravity/brain`) and legacy CLI (`~/.gemini/antigravity-cli/brain`) transcripts automatically, and exiting `1` on failure (`#119`). Sealing simultaneously indexes a Markdown Flight Record into `<project>/joshua_os/archive/history.db` (WAL-mode SQLite FTS5) for unlimited project-scoped `/aim-sessions` (`./aim sessions`, `./aim search-sessions` with `_sanitize_fts5_query()` safe quoting for hyphens, dots, and `#`, `./aim recall`, and `./aim audit` — all propagating `rc=1` on missing/corrupt `history.db`, `#124`, `#134`) recall. Automated headless LLM pipelines (`reasoning_utils.py`) pass `--project ephemeral-pipeline` and invoke `cleanup_ephemeral_agy_sessions()` in `finally` blocks so background jobs never pollute interactive session history. Operators can diagnose vault keys (`keyring` + `~/.aim/blackbox.key`) via `aim vault doctor`.
4. **Baton Pass (Tier 2 POSIX Optional):** On POSIX hosts (`tmux` on Linux, WSL, macOS), the agent optionally spawns the next agent vessel and injects `HANDOFF.md` directly into its prompt; on native Windows 10/11 (Tier 1), continuity completes via the committed `HANDOFF.md` + `memory-wiki/` state and sealed Blackbox Vault.
5. **Rolling-Window `HANDOFF.md` Hygiene (`< 12 KB` Target, `#136`):** When `HANDOFF.md` `§0` accumulates multi-sprint historical rows already captured in `memory-wiki/` and `CHANGELOG.md`, vault the complete byte-for-byte pre-compaction `HANDOFF.md` (`SHA-256` verified) inside an archival GitHub Issue `<details>` block (`#136`) before compacting older eras into concise era-index rows with explicit retired-module tombstones while preserving `100%` of `§5` Critical Traps & Warnings.

## LanceDB Retrieval (Two-Tier Protocol)
A.I.M. uses LanceDB for semantic hybrid retrieval (RAG 5.21). When an agent needs to retrieve factual knowledge, it must natively act as a retrieval agent using the Two-Tier Protocol (see [Architecture](architecture.md)):
1. **Primary (Native Multi-Harness MCP — Pure Automatic Mode):** `register_mcp.py` auto-registers the `search_lancedb(query, top_k=10)` tool across `agy`, `grok`, `codex`, `opencode`, and existing `cursor`/`claude` configs with **zero path or scope parameters** required from the LLM:
   - **Local-First & Cross-Platform URI Decoding:** `_uri_to_local_path()` in `mcp_lancedb.py` normalizes POSIX (`file:///path`), percent-encoded (`%20`), and Windows (`file:///C:/Users/...`) `params.workspaceFolders[0].uri` paths (falling back to `AIM_WORKSPACE_ROOT` or `os.getcwd()`). If the workspace root contains `joshua_os/memory_lance`, it queries that project's isolated cartridge directly.
   - **Opt-In Umbrella & Fail-Closed (`#94`, `#141`):** If the agent is opened in a parent/umbrella directory with no root `joshua_os/memory_lance`, umbrella discovery runs **only** with `AIM_UMBRELLA_SCAN=1` (read-only, merged by score, `[Source: <subproject>]`). When no project DB exists — including Desktop launches from `$HOME` or `/` — the server returns `[NO PROJECT MEMORY DB]`; it never borrows the shared engine's DB or another project's memory. `AIM_MEMORY_DB=<abs path>` is the explicit one-off override. The server code may run from the shared engine at `~/.aim/engine`, but the database stays per project.
   - **Explicit `db_path` Cartridge Resolution (`#99`, `#130`):** `mcp_lancedb.py` passes `db_path=` explicitly into `retriever.perform_search(..., db_path=...)` (`get_active_aim_root(db_path=db_path)`) without mutating module-global `LANCE_DB_PATH`, resolving supplemental `<project>/joshua_os/archive/cartridges` inside the target project and reranking results via pure-Python `EntityIntersectionReranker` (dead `flashrank` dependencies removed).
2. **Fallback (CLI-Agnostic, `#123`):** If an agent is spawned in a vessel that does not support MCP, it degrades cleanly to executing the local project launcher (`./aim search "<query>"` on POSIX; `.\aim.ps1 search "<query>"` or `.\aim.cmd search "<query>"` on Windows) or the project venv Python interpreter — never bare `python3` on Windows (`rc=9009` Microsoft Store stub).


## OpenCode Skill Invocation (2026-11-28)
- Skills are **not** slash commands. `opencode debug skill` lists IDs; invoke via `@<id>` as plain text, natural language ("use the `aim-handoff` skill"), or a custom `~/.config/opencode/commands/*.md` wrapper.
- The `@` picker is primarily a file picker; selecting `handoff_pulse_generator.py` is **not** the `aim-handoff` skill.
- `handoff_pulse_generator.py` is the `./aim handoff` pulse/flight-record CLI (`cmd_handoff`), not the closeout skill.
- Slash wrappers (`/aim-*`) are pending; the skill library's `Slash:` lines are aspirational, not installed commands.
